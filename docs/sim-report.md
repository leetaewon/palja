# 시뮬레이션 보정 기록

> `npm run sim:lives` 출력과 보정 과정 (PRD 6-1, 12장 Phase 3).
> 봇: 마음가짐은 대체로 지난해 유지(75%)하고 가끔 무작위로 바꾸며, 갈림길은 무작위로 고른다.
> 왕족은 출생의 1%라 1만 인생에 100명 남짓이다. 왕족 줄과 왕족 목표는 왕족만 따로 더 태워 300명 이상으로 계산한다(출생 비율·전체 평균에는 넣지 않는다).
> `npm run test`는 같은 목표를 시점마다 표본 4,000으로 확인한다 (`tests/sim.test.ts`, `tests/era-*.test.ts`).

### Phase 4 다시 확인 (2026-11-04)
콘텐츠를 고친 뒤(660 현대 지식 4단계, `royal-660-lineage`·`royal-1170-birth`의 겹친 족보 기록 제거) 4개 시점을 각 1만 인생으로 다시 돌렸다. 위 표의 수치와 같다(660·1170 기록 없음 77.6%·82.1%, 1592 성인 평균 45.7세). 1592 `common-epidemic` 사망 0.05 → 0.045는 성인 평균을 45.8세로밖에 올리지 못해 되돌렸다(결정 기록).

### 통합 세션에서 바뀐 것과 그 영향

| 바뀐 것 | 영향 |
|---|---|
| 같은 해 연쇄 사건 수정: 연초에 조건이 안 맞던 연표 사건을 그 달에 다시 판정 | 1592에서 한 번도 일어나지 않던 `1592-refugee-road`(피난길), `1593-jinju-fall`(진주성 함락), `1597-south-ravaged`·`1597-refugee`(정유재란)가 콘텐츠 설계대로 일어난다. 1592 전란 사망 3.3% → 7.6%, 성인 평균 48.1 → 44.2세(표본 4000)로 목표를 벗어났다 |
| 진주성 모임 갈림길(1593년 5월)에 확률 0.25 | 경상도 전체가 아니라 진주 인근 사람만 모여들었다. 전란 사망 5.4%로 |
| 1592 시점 보정 1.0 → 0.95 | 전체 평균을 목표 가운데로(24.6 → 25.3세). 성인 평균은 시점 보정에 거의 움직이지 않았다(0.92에서도 46.5세) — 성인 평균을 끌어내리는 것은 10~30대에 겪는 전쟁 사건이기 때문 |
| 기록 규칙에 시점 조건, 660·1170용 호적·족보·왕실 규칙 추가 | 기록 분포는 비슷하게 유지(660 기록 없음 78.0 → 77.6%, 1170 83.0 → 82.1%). 1170·660에서 조선 문장이 사라졌다 |
| 공통 사건 합치기(common-shared.json), 1592 재혼 사건, 부곡민·군인 마음가짐 | 사건 순서가 바뀌어 난수 흐름이 달라졌다. 4개 시점 모두 목표 유지 |

- 1592 성인 평균 45.7세는 하한(45)에 가깝다. 전쟁이 10~30대를 덮치는 시점이라 낮은 것이 자연스럽지만, 1592에 성인 사망 사건을 더하면 목표를 벗어날 수 있다. 그때는 `common-1592.json`의 성인 일상 위험(역병·사고)을 조금 낮춰 맞춘다.
- 1800s 왕족은 역모 고변(`royal-1800s-treason`)으로 일찍 죽는 일이 있어 다른 시점보다 평균이 낮다(32.5세). 표본 4000의 왕족 30여 명으로는 평균이 전체보다 낮게 나오는 일이 있어 왕족 표본 보강을 넣었다.
