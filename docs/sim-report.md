# 시뮬레이션 보정 기록

> `npm run sim:lives` 출력과 보정 과정. 시점이 늘면 시점별로 덧붙인다 (Phase 3).
> 봇: 마음가짐은 대체로 지난해 유지(75%)하고 가끔 무작위로 바꾸며, 갈림길은 무작위로 고른다.

- 20대 사망이 다른 나이대보다 많은 것은 전쟁(1592~1598)을 10~20대에 겪기 때문이다. 이 시점의 특징이라 그대로 둔다.
