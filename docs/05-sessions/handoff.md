## 3. PR 검토 방법

1. 연결된 `palja` 폴더에서 `git fetch origin`
2. 폴더 밖(작업 셸의 `$HOME/work`)에 클론해서 해당 브랜치 체크아웃 → `npm ci`
3. `npm run test`, `npm run lint`, `npm run build`
4. `npm run sim:lives -- --era <시점>` 4개 시점 → PRD 6-1 보정 목표(평균 사망 20대 중반, 5세 이전 30~40%, 성인 45~55세, 왕족 1%±0.3%p, 왕족·상위 신분이 평균보다 오래 삶). 연출만 바꾼 PR이라도 엔진·콘텐츠를 건드렸으면 다시 돌린다.
5. 엔딩 기록에 다른 시점 템플릿이 나오지 않는지 (`tests/era-integration.test.ts`)
6. 화면 변경은 Cloudflare 미리보기 링크를 휴대폰·데스크톱에서 직접 플레이. 시드 `era3`(660)·`era89`(1170)·`era27`(1592)·`era55`(1800s)는 E2E와 같은 인생이다.
7. 사용자 맥에는 Playwright 브라우저가 없어 E2E는 PR 본문 결과와 직접 플레이로 확인한다.

## 4. 핵심 결정 (자세한 건 `docs/04-decisions.md`)

- 시점 4개: 660 백제 멸망 · 1170 무신정변 · 1592 임진왜란 · 1800년대 세도정치
- 왕족 출생 1/100로 보정하고 플레이어에게 안내 (실제는 약 1/10,000 이하)
- 현대 지식은 회귀한 인생부터 허용. 효과는 영향력 4단계(가족·마을·고을·나라)로 신분에 따라 제한. 시점별 문장은 `knowledge.json`의 `byEra`
- 바꾼 결과는 그 인생 안에서만 유지 (대체 역사는 확장 후보)
- 기록 템플릿은 `eras`로 시점을 거른다 (`judgeRecord`). 모든 시점에 `royal`·`yangban`(상위 신분) id가 있어야 한다
- 문체: 일생은 담담한 서술체, 엔딩 기록만 고풍
- 모바일 우선, 라이트 기본 + 다크 전환, 화면 크기별로 레이아웃만 다름
- 배포 Cloudflare Pages, 사이트 절대 주소는 `VITE_SITE_URL` 한 곳에서
- 커스텀 도메인(palja-game.com/.kr)은 링크를 퍼뜨리기 전에 바꿀 것 (localStorage가 주소별이라 기록이 옮겨 가지 않음)
